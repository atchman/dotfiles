### BackUp dotfile with symlinks
#### Erstellen

to move file:\
  ``` $ mv FILEPATH GITPATH ```

create symlink:\
  ``` $ ln -s GITPATH FILEPATH ```

#### Wiederherstellen
1. ``` git clone Repo ```
2. ``` run backUp.sh ```
